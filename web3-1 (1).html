Product

Everything a vault needs, nothing it doesn't.

Abagus is a single self-contained page — open it once and it keeps working offline. Every feature below runs on your device, in the tab you have open right now.

Layered encryption

AES-256-GCM and XChaCha20-Poly1305 both authenticate your data by default, so one cipher's weakness alone isn't enough to break the payload.

Keyfiles & checksums

Pair your passphrase with an optional keyfile as a second factor, and verify every recovered file against a SHA-256 checksum shown at lock time.

Streamed, chunked payloads

Files are encrypted in chunks off the main thread, so multi-gigabyte files don't need to fit in memory and the interface never freezes.

Guide

Get started in under a minute.

No account, no setup — just drop a file, set a passphrase, and you're done. Here's the whole flow, start to finish.

01

Open the Lock tab

Scroll down to the app panel below — "Lock" is selected by default, ready for a file.

02

Drop in your file(s)

Drag a file onto the drop zone, or click it to browse. You can queue up more than one file at a time.

03

Choose a passphrase

Pick something you'll remember, at least 12 characters — Abagus won't encrypt with anything shorter, since that passphrase is the only way the file can ever be opened again. Attach an optional keyfile for an extra layer if you'd like.

04

Press Encrypt

Your file is locked right there in the tab. Save the checksum you're shown alongside the encrypted file — you'll use it to confirm everything came through intact later.

05

Switch to Unlock when you're ready

Drop in the encrypted file, enter the same passphrase (and keyfile, if you used one), and press Decrypt.

06

Download your file

Recovered files show up with a quick preview and a download button — grab them whenever you're ready.
